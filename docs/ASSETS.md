# Asset provenance and third-party notices

BELOW LEVEL 6 was authored as a new project with Codex assistance. MERIDIAN
SUBSURFACE SYSTEMS, UNIT 06, characters, signs, work orders and radio dialogue are
fictional project material. No material was extracted from another game.

| Material | Author / origin | Source and license treatment |
| --- | --- | --- |
| Facility architecture, server racks, pipes, consoles, furnishings, observation anomalies | Original project work | Built by the procedural environment code in `environment/`; covered by the project's root license. |
| Observer body, technician presentation, CCTV double | Original project work | Authored in `ai/`, `player/` and `systems/`; covered by the project's root license. |
| Interface, fictional signage, story, documents and puzzle procedures | Original project work | Authored in the source repository; covered by the project's root license. |
| Executable glyph | Original project work | `assets/icon.svg`; matching multi-resolution `assets/icon.ico` generated by `tools/generate_audio.py`; covered by the project's root license. |
| 40 non-speech WAVs: ventilation, electrical hum, fans, servers, drone, five footstep surfaces, mechanisms and signals | Original procedural sound synthesis | `tools/generate_audio.py`; deterministic NumPy/SciPy synthesis without sampled commercial audio. Covered by the project's root license. |
| Six radio WAVs | Original dialogue and processing; Microsoft David Desktop voice | Speech rendered offline through the Windows `System.Speech` API, then processed into radio audio. Only resulting recordings ship; Microsoft's voice software and voice data are not redistributed. The project license covers its original text and processing code and does not relicense Microsoft's proprietary voice software. |
| Text fonts | Installed Windows system fonts, selected at runtime | The interface requests Consolas/Cascadia Mono/monospace through Godot's `SystemFont`. Font binaries are not copied into the repository or distribution. |
| Godot Engine 4.5.2 | Godot Engine contributors; Juan Linietsky and Ariel Manzur | Official Windows x64 release export template. MIT license text is in `licenses/GODOT_LICENSE.txt`. |
| Godot bundled libraries | Authors listed in the upstream copyright notice | Exact upstream 4.5.2 `COPYRIGHT.txt` is preserved as `licenses/GODOT_THIRD_PARTY.txt`; it includes library attributions and their license texts. |

The generation scripts use NumPy, SciPy, Pillow and Windows speech as development
tools. Those Python libraries, Python itself, speech services, engine editor and
export templates are not runtime dependencies of the shipped game. The release
executable contains Godot and the game's resource pack.

The optional microphone feature is not implemented. The game neither requests
microphone access nor records the player's voice. Fake renderer failure is a
scripted scene inside the game window.
